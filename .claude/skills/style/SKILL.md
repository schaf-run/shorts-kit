# style

Стиль = `brand/theme.css` (цвета и шрифты) + `brand/fonts/` + `brand/brand.json` (подпись @ник на слайдах). Шаблоны видео и каруселей берут его при каждом рендере; сами шаблоны не трогай.

1. Покажи текущий стиль: `tools/vid preview` (~1 минута), затем открой `brand/preview/video.jpg` и `brand/preview/carousel.jpg` (Read) и открой папку пользователю (WSL: `explorer.exe "$(wslpath -w brand/preview)"`).
2. Расспроси, коротко, по одному-два вопроса за раз (AskUserQuestion, где есть варианты): для чего ролики и какое настроение (строго/тепло/дерзко/спокойно); тёмный или светлый фон; есть ли фирменные цвета (hex или «как на моём логотипе» - можно прислать картинку); какой шрифт нравится или ассоциации (`references/fonts.md`); ник для слайдов. Дай 2-3 готовых направления из `references/palettes.md` как отправную точку.
3. Сохрани прежний вариант: `cp brand/theme.css brand/history/theme-$(date +%Y%m%d-%H%M).css` (создай папку при необходимости).
4. Шрифты: `tools/vid font ID --role sans` (основной) и `tools/vid font ID --role accent [--style italic|normal]` (акцентный, для выделенных слов). Команда сама скачает файлы и перепишет нужный блок в theme.css. Только шрифты с кириллицей (команда проверит).
5. Цвета: отредактируй `:root` в `brand/theme.css` по правилам `references/palettes.md` (все переменные обязательны; контраст текста и фона). Ник - в `brand/brand.json` (`"handle"`).
6. `tools/vid doctor` (строка «стиль brand/theme.css» должна быть OK), затем `tools/vid preview` и покажи результат. Правь, пока пользователю не понравится; каждое крупное изменение - новый preview.
7. Готово: скажи пользователю, что новый стиль применится ко всем следующим роликам и каруселям, а старые файлы не изменятся (чтобы обновить готовый ролик, его нужно перерендерить: `tools/vid edit ПУТЬ --from compose`). Как вернуть прежний стиль: скопировать файл из `brand/history/` обратно в `brand/theme.css`.
