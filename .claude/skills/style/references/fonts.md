# Шрифты с кириллицей (id для `tools/vid font`)

Все - бесплатные (Google Fonts через Fontsource), с кириллицей. Список не полный: подойдёт любой id с fontsource.org, если у шрифта есть кириллица (команда проверит).

## Основной (--role sans): текст, заголовки, субтитры
Нужны начертания 400/600/800 (если каких-то нет, команда возьмёт ближайшие).
| id | Характер |
|---|---|
| inter | нейтральный, технологичный (текущий по умолчанию) |
| manrope | современный, мягкий, дружелюбный |
| montserrat | широкий, уверенный, «маркетинговый» |
| onest | российский гротеск, чистый, спокойный |
| golos-text | российский гротеск, читаемый, деловой |
| rubik | округлый, тёплый |
| ibm-plex-sans | инженерный, строгий |
| fira-sans | гуманистический, читаемый |
| jost | геометрический, стильный |
| nunito | мягкий, округлый, лёгкий |
| raleway | элегантный, тонкий |
| exo-2 | техно, спорт, игры |
| roboto-condensed | узкий, плотный - много текста в строке |
| oswald | узкий, крупные заголовки, плакатный (только 200-700) |
| unbounded | широкий дисплейный, яркий, молодёжный |

## Акцентный (--role accent): выделенные слова в субтитрах, `.ser` и `_курсив_` в графике
Нужны начертания 400/700.
| id | Стиль | Характер |
|---|---|---|
| pt-serif | italic | классический, спокойный (текущий по умолчанию) |
| playfair-display | italic | контрастный, модный, «журнальный» |
| lora | italic | мягкий книжный |
| cormorant-garamond | italic | изящный, дорогой, тонкий |
| merriweather | italic | плотный, хорошо читается мелко |
| eb-garamond | italic | старинный, литературный |
| caveat | normal | рукописный, живой |
| unbounded | normal | тот же приём, что у основного: жирный широкий акцент вместо курсива |

Сочетания, которые работают: inter + pt-serif (строго), manrope + playfair-display (мягко и модно), montserrat + lora (уверенно и тепло), golos-text + cormorant-garamond (деловой премиум), rubik + caveat (дружелюбно, живо), unbounded + playfair-display (ярко).
