# Цвета: переменные темы и готовые направления

## Переменные (все обязательны, `brand/theme.css`, блок :root)
| Переменная | Где видна | Правило |
|---|---|---|
| --bg | фон кадра и слайда | самый тёмный (или самый светлый в светлой теме) |
| --panel | карточки | на 3-6% светлее/темнее фона |
| --panel-2 | чипы, вторичные плашки | ещё на 3-4% дальше от фона |
| --text | основной текст, иконки, обводка кружка | контраст к --bg не меньше 7:1 |
| --muted | подписи, второстепенное | контраст к --bg не меньше 4.5:1 |
| --overlay-text | субтитры поверх видео | почти белый (или --text); читается на любом кадре |
| --accent | заливка акцентных карточек, выделение `.mark` | насыщенный; текст --text на нём читается (4.5:1) |
| --accent-hi | линии, маркеры, подчёркивания, кольцо кружка | ярче --accent; заметен на --bg (3:1) |
| --edge | рамки | --text с прозрачностью 0.12-0.2: `rgba(r, g, b, 0.16)` |
| --line | сетка фона | --text с прозрачностью 0.04-0.06 |
| --vignette | затемнение краёв фона | тёмная тема `rgba(0, 0, 0, 0.55)`, светлая `rgba(0, 0, 0, 0.08)` |
| --font-sans, --font-accent, --accent-style | шрифты | меняет `tools/vid font`, вручную не нужно |

Сплошные цвета (--bg, --panel, --panel-2, --text, --accent, --accent-hi) пиши в hex `#rrggbb`: анимации смешивают их в JavaScript. Прозрачность - только в --edge и --line.

Контраст проверяй расчётом (python, формула WCAG relative luminance), а не на глаз; `vid carousel` дополнительно предупредит о слабом контрасте текста.

| Бумага и чернила (светлая) | #f4f0e8 | #ebe5d9 | #e2dac9 | #1d1b18 | #6b645a | #ffffff | #f2c14e | #c2410c |
| Белый и фиолетовый (светлая) | #f7f7fb | #ececf4 | #e2e2ee | #17152b | #676582 | #ffffff | #c9bcff | #5b3fd1 |

Светлые темы: --accent - светлая заливка (на ней тёмный --text), а насыщенный цвет уходит в --accent-hi; --edge и --line делай от тёмного --text (`rgba(29, 27, 24, 0.16)`); --vignette слабый; --overlay-text оставляй белым - эти субтитры лежат на видео (в режиме кружка субтитры идут цветом --text по фону).

Проверено расчётом для всех строк таблицы: text/bg >= 13, muted/bg >= 5, text/accent >= 5.5, accent-hi/bg >= 3.1.
