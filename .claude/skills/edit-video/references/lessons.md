# Технические уроки (почему vid устроен так)

## Распознавание речи
- Русская речь: GigaAM v3 (e2e-RNNT) + Silero VAD через onnx-asr, без PyTorch. Он дословный: брошенные дубли и мат остаются отдельными сегментами, а не склеиваются в одно чистое предложение с растянутыми границами слов, как у Whisper. Поэтому дубли находятся надёжно. У слов нет «уверенности» (p).
- Язык определяется Whisper base по 4 окнам по 30 с речи, разбросанным по файлу: одно первое окно ошибалось из-за шума и тишины в начале.
- Английская речь: faster-whisper large-v3-turbo (скачивается при первом английском видео, ~1.6 ГБ).

## Дубли (takes)
- Нарезка по децибелам резала каждый вдох на куски, и почти все выглядели «незаконченными». Единица дубля - сегмент распознавания.
- Для Whisper сегмент дополнительно делится на паузе > 1 с: VAD иногда склеивает две попытки в один сегмент.
- Не решено: оговорка, исправленная на том же дыхании, сидит внутри одного предложения и требует ручного выреза в cuts.json.

## Звук на стыках
- Границы всегда проверяй по реальной тишине в звуке, а не по времени слов: одно слово может «поглотить» длинную паузу.
- Каждый кусок получает микро-затухание 10 мс - без щелчков на стыках.

## Рендер HyperFrames
- Входной HTML должен лежать внутри проекта HyperFrames: vid кладёт шаблон в `tools/hyperframes/.tmp/<hash>.html` и ставит клип рядом.
- Длительность корня (`data-duration`) читается один раз до скриптов - vid вписывает её в HTML, округляя вниз по сетке кадров.
- Видео - `<video muted>` со своими data-start/duration, звук - отдельный `<audio>`.
- Пути к ассетам - от корня проекта (`assets/...`), шрифты - только локальные @font-face (общий fallback вроде Georgia вызывал загрузку Google Fonts).
- Исходный клип: SDR bt709 и ключевой кадр каждую секунду, иначе рендер переключается в HDR или кадры замирают при перемотке. vid cut это обеспечивает.
- Эмодзи внутри SVG `<text>` рисуются пустым квадратом (в рендерере нет шрифта эмодзи): используй иконку Lucide или слова.
- CSS-переменная с именем `--caption` в рендере HyperFrames не работает (цвет молча падает на унаследованный), любое другое имя работает - поэтому цвет субтитров поверх видео называется `--overlay-text`. Не называй переменные темы `--caption...`.
