# setup

Пользователь не программист: объясняй по-русски, коротко, без жаргона; каждую команду, которую он должен выполнить сам, давай одной строкой для копирования.

1. `tools/vid doctor` (если `tools/.venv` ещё нет - сразу шаг 2). Каждая строка FAIL - что не так и как починить.
2. Системные части (ffmpeg, библиотеки Chrome, первый запуск) требуют пароль, его вводит только пользователь. Попроси его открыть **второе окно** терминала Ubuntu (в Windows: меню Пуск -> Ubuntu), выполнить `cd ПУТЬ_К_ПРОЕКТУ && bash install.sh`, ввести пароль от Ubuntu (символы при вводе не видны - это нормально) и написать тебе, когда появится «Готово» или ошибка. Путь подставь сам (`pwd`).
3. Если системные пакеты уже стоят и не хватает только своих частей (Python-окружение, npm-пакеты, модели) - запусти сам: `bash install.sh --user-only` (в фоне: скачивание моделей ~1 ГБ идёт минуты).
4. Ошибки установки:
   - нет интернета или таймаут при скачивании - повторить `bash install.sh` позже (он продолжит с того же места);
   - `Chrome для рендера` FAIL - `cd tools/hyperframes && npx hyperframes browser ensure --force`, затем `npx hyperframes doctor` покажет, каких системных библиотек не хватает (ставятся через `sudo apt-get install ...` пользователем);
   - `свободно на диске` FAIL - нужно минимум 5 ГБ: предложи удалить старые папки `videos/*.work` (спроси, какие);
   - папка проекта на диске Windows (`/mnt/c/...`) - всё будет медленно: предложи перенести проект внутрь Ubuntu (`docs/01-install.md`).
5. В конце `tools/vid doctor` должен напечатать «ВСЁ ГОТОВО». Затем предложи сделать первый пробный монтаж (`docs/02-video.md`) или настроить свой стиль (скилл style).
