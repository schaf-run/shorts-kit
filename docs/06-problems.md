# Если что-то не работает

**Первое, что стоит сделать:** написать Claude «что-то не работает, проверь установку». Он запустит проверку `tools/vid doctor` и скажет, что чинить.

## Частые ситуации
| Что видите | Что делать |
|---|---|
| При старте Claude пишет «окружение не установлено» | Запустите в окне Ubuntu: `cd ~/shorts-kit && bash install.sh` |
| `claude: command not found` | Откройте новое окно терминала. Не помогло: `bash install.sh` ещё раз |
| Установка оборвалась (интернет) | Просто запустите `bash install.sh` снова - продолжит с того же места |
| Пароль не вводится | Он вводится, просто не показывается. Наберите и нажмите Enter |
| Всё очень медленно | Проверьте, что проект в `~/shorts-kit`, а не в `/mnt/c/...` (см. установку) |
| Claude не находит видео | Дайте полный путь в кавычках: Shift + правая кнопка -> «Копировать как путь» |
| В субтитрах слово с ошибкой | «в субтитрах пиши X вместо Y» |
| Кружок режет лицо | В кадре должен быть один человек; отойдите от камеры при съёмке |
| Закончился лимит Claude | Подождите, пока он обновится, или используйте шаблон simple |
| Мало места на диске | Удалите старые папки `videos/*.work` (там промежуточные файлы) - Claude поможет |

## Где что лежит
- `videos/<имя>.work/out/final.mp4` - готовый ролик.
- `videos/<имя>.work/notes.md` - что делалось с роликом (Claude читает при повторном монтаже).
- `carousels/<название>/out/` - слайды.
- `brand/` - ваш стиль.

## Приватность
Видео и звук обрабатываются только на вашем компьютере. В Claude уходят: текст расшифровки, решения о монтаже и несколько кадров для проверки. Анонимная статистика HyperFrames отключена.
