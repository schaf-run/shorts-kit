# Установка

Делается один раз. Установщик сам скачает всё нужное (около 3 ГБ): программу для видео ffmpeg, Python, Node.js, модели распознавания речи, программу отрисовки HyperFrames и Claude Code.

## Windows 10/11

### 1. Включите WSL (Linux внутри Windows)
1. Нажмите Пуск, наберите **PowerShell**, нажмите правой кнопкой -> **Запуск от имени администратора**.
2. Вставьте и нажмите Enter:
   ```
   wsl --install -d Ubuntu
   ```
3. Перезагрузите компьютер, когда попросит.
4. После перезагрузки откроется окно **Ubuntu** (или откройте его сами: Пуск -> Ubuntu). Придумайте имя пользователя (латиницей) и пароль. **Пароль при вводе не отображается** - это нормально. Запомните его: он понадобится при установке.

### 2. Скачайте проект
В окне Ubuntu выполните (по одной строке):
```
cd ~
git clone https://github.com/schaf-run/shorts-kit.git shorts-kit
cd shorts-kit
```
Проект должен лежать внутри Ubuntu (`~/shorts-kit`), а не на диске C: - так всё работает в разы быстрее.

### 3. Запустите установку
```
bash install.sh
```
Введите пароль от Ubuntu, когда спросит. Установка идёт 20-40 минут (зависит от интернета). В конце появится список проверок и слово **Готово**.

### 4. Запустите Claude
Откройте **новое** окно Ubuntu и выполните:
```
cd ~/shorts-kit
claude
```
При первом запуске Claude попросит войти в аккаунт - откроется браузер. Всё, можно работать.

## macOS
1. Откройте **Терминал** (Программы -> Утилиты -> Терминал).
2. Если `git` не установлен, macOS сама предложит установить инструменты разработчика - согласитесь.
3. Выполните по одной строке:
   ```
   cd ~
   git clone https://github.com/schaf-run/shorts-kit.git shorts-kit
   cd shorts-kit
   bash install.sh
   ```
   Установщик поставит Homebrew (если его нет), ffmpeg и Node.js - попросит пароль от Mac.
4. Откройте новое окно Терминала: `cd ~/shorts-kit` и `claude`.

## Как передать видео и забрать результат (Windows)
- **Проще всего**: в Проводнике нажмите на видео с зажатым Shift правой кнопкой -> **Копировать как путь**, вставьте путь в сообщение Claude: «смонтируй "C:\Users\...\видео.mp4"». Claude сам найдёт файл.
- **Или** положите видео в папку проекта: в адресной строке Проводника наберите `\\wsl$\Ubuntu\home\ИМЯ\shorts-kit\videos` (ИМЯ - ваше имя пользователя в Ubuntu) и перетащите файл туда. Эту папку удобно закрепить в «Быстром доступе».
- Готовый ролик Claude откроет сам в окне Проводника. Он лежит в `videos\<имя видео>.work\out\final.mp4`.

## Обновление проекта
В папке проекта: `git pull`, затем `bash install.sh` (докачает только то, что изменилось).
