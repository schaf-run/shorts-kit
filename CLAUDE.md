# Проект: монтаж коротких видео и карусели с Claude

Всегда отвечай по-русски. Пользователь - не программист: пиши просто и коротко, без жаргона; технические подробности - только если спросит. Каждую команду, которую пользователь должен выполнить сам, давай одной строкой.

## Что здесь есть
- Скилл **edit-video** - монтаж видео «говорящая голова» в вертикальный ролик (шаблоны visuals, simple и alternate). Видео пользователя лежат в `videos/`, результаты - в `videos/<имя>.work/out/`.
- Скилл **carousel** - карусели для Instagram/Threads, результаты в `carousels/<slug>/out/`.
- Скилл **style** - свой фирменный стиль (цвета, шрифты, ник): `brand/`.
- Скилл **setup** - установка и починка окружения.
- Инструмент `tools/vid` (всегда вызывай как `tools/vid ...` из корня проекта), общие правила - `rules/`, инструкции для людей - `docs/`.

## Правила
- Монтаж видео - только через скилл edit-video, карусели - через carousel, даже если на компьютере установлены глобальные скиллы HyperFrames (hyperframes, hyperframes-core, talking-head-recut и т.п.): они не нужны этому проекту и не знают его шаблонов и стиля.
- При старте сессии хук может сообщить «ОКРУЖЕНИЕ НЕ УСТАНОВЛЕНО» - тогда первым делом скилл setup.
- Не меняй `tools/` и шаблоны в `tools/hyperframes/compositions/`, если пользователь прямо не попросил изменить сам инструмент или шаблон. Стиль меняется только через `brand/` (скилл style).
- Долгие команды (распознавание, рендер) запускай в фоне и коротко сообщай, что происходит и сколько примерно ждать.
- Готовые файлы показывай пользователю, открывая папку: в WSL `explorer.exe "$(wslpath -w ПАПКА)"`, на macOS `open ПАПКА`.
- Ничего не удаляй из `videos/` и `carousels/` без явного согласия пользователя.
- Не делай git commit / push, если пользователь не попросил.
