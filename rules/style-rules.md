# Правило стиля: стиль постоянный, графика каждый раз новая

- **Стиль** = цвета и шрифты из `brand/theme.css`. Он общий для обоих шаблонов видео и для каруселей, чтобы все материалы узнавались как одна серия. Никогда не меняй стиль ради одного ролика или карусели и не добавляй в биты и слайды новые цвета и шрифты - только переменные темы.
- Менять стиль можно только по просьбе пользователя и только через скилл style: он правит `brand/theme.css` и `brand/fonts/`, а шаблоны подхватывают изменения при следующем рендере.
- **Графика** (visuals и карусели) каждый раз проектируется заново из содержания: схемы, диаграммы, иконки, макеты интерфейсов, графики - а не один и тот же набор карточек по кругу.
- Шаблон simple графики не содержит: только видео и субтитры.
